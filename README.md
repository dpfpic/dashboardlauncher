# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-28

### Added
- Initial public release.
- Fully admin-configurable shortcut buttons (title, icon, size, route, order, group-based visibility, active toggle).
- Custom icon upload with per-instance icon storage.
- Built-in icon library, browsable from the admin panel.
- Adjustable icon sizes (small / medium / large / extra large).
- Configurable dashboard title, welcome message (with `{displayName}` placeholder), and footer text.
- Responsive grid layout, adapting to a compact multi-column view on mobile devices.
- Loading spinner and page-freeze on button click to prevent duplicate navigation.
- Full English and French translations.
